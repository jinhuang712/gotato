# Glossary

One name for each thing in Gotato, with its meaning in one line. When the code still uses an older name, the last column says so, until the code catches up.

The two central terms match how Anthropic's and OpenAI's agent APIs use them: an **Agent** is a definition, and a **Session** is a live conversation that runs one.

## Where to start

The terms come in three tiers. Read the first tier and you can use Gotato; read the others when you need them.

| Tier | You meet it when | Terms |
|---|---|---|
| **1. Everyday** | you build an agent and run it | Agent, Session, Run, Turn, Message, Model, Tool, Effect, Event, Subscription, Steer, FollowUp, Interrupt, Abort |
| **2. Running a service** | you keep Sessions in a store and run many Instances | Runner, AgentProfile, TaskSpec, Registry, Store, Definitions, Record, Instance, Writer, Claim, Drain, Admission, Admitter, Not writer, Not run, Retryable, Warm Session, TTL |
| **3. Inside and extending** | you tune long Sessions, write an adapter, or add your own seam | Context, Context builder, Context block, Compaction, Segment, Recap, Checkpoint, Entry, Fact, Log entry, Journal, Feed, Event source, Extension, ToolSet, Tool catalog, Catalog, Tool search, Model config, Model facts, Model bridge, Epoch, Record epoch, Liveness row |

[guides/extension-points.md](guides/extension-points.md) says which seam does what.

## Core

| Term | Meaning | Not | In code today |
|---|---|---|---|
| **Agent** | A named, reusable definition: model, instruction (with any reference text it carries, such as a schema or a runbook), tools, the highest Effect its tools may have, Sampling, limits and its compaction ceiling. It holds no conversation, no state and no status, and it owns its instruction and ceiling: a Session has neither of its own, so another instruction is another Agent. One Agent runs many Sessions. How a host keeps its Sessions, such as their TTL, is the host's setting and not the Agent's. | agent spec, agent config, template, sub-agent, child agent, worker, supervisor (roles belong to applications) | `profile.AgentProfile` (see **AgentProfile**), whose typed fields (`ToolSets`, `Sampling`, `Extensions`, `ToolSearcher`, ...) the Runner turns into every `SessionOption`; it has no `Options`. With the Go API alone, the options passed to `gotato.NewSession`. |
| **Session** | The minimal unit a system interacts with: one conversation running one Agent. It is a Loop and a Runtime, and its ID is its Record's ID. The live Session exists during a Run: the Runner builds it over the Record and its Writer when a Run starts (`startRun`), and closes it when the Run settles (`detach`), after taking the messages left in its queues. While a Run goes, the live Session has a Status, a state machine and queues for Steers, FollowUps and notices, holds its Transcript, its Context and its tools, and uses the connections its Instance shares. It manages itself: it saves itself and checks its own health. Between Runs only the warm Session stays in memory, which is its Record and its Writer with no queue, and its own timer compacts it shortly before its prompt cache expires or its time to live (TTL: 60 idle minutes unless the host's `Config.Warm` sets another) ends, whichever comes first, unless that is turned off; at the end of its TTL it leaves memory. Its Record stays in the Store, and any Instance can load it again. It is bound to no Instance. Everything inside it is hidden behind its API, which can still show its Context and Transcript for inspection. | conversation, thread, actor, instance | `gotato.Session`, the live Session, built for each Run and closed when it settles ([specs/session.md](specs/session.md)). `host.Runner` holds the run handle, and the Session's `store.Writer` writes each Step. |
| **Warm Session** | A Session's copy that stays in memory after its Run: its Record and the Writer that wrote it. It is a cache, never a lock: while it idles it holds no Claim, so another Instance can take the Session over and its copy is dropped. Before each Run the Instance compares the Record's head in the Store with the copy's, and reloads when it changed. It leaves after its TTL, and its own timer compacts it before its prompt cache expires. It counts toward the Activation limit, and is the first thing evicted at the limit. | cached Session, pinned Session, actor | `host.WarmPolicy` (`host.Config.Warm`), `Runner.WarmSessions`, `store.Writer.Stale` and `Resume`; the Runner builds a `gotato.Session` over the copy for each Run and closes it when the Run settles ([specs/multi-instance.md](specs/multi-instance.md)). |
| **TTL** | The time to live of a warm Session: how long it stays in memory while idle, 60 minutes unless the host's setting says another. The Store keeps the Session; only the memory goes. | session timeout, expiry of the Session | `host.WarmPolicy.TTL` (`host.Config.Warm`) |
| **Record** | What the Store keeps of a Session: an append-only log of Entries. Its Facts (Messages, Tool calls that started, tools that loaded or unloaded, metadata changes, Claims and Checkpoints) rebuild the Session, and its Log entries (Runs, usage, model calls, retries, the parts of a streaming reply) record what happened. Every Entry is also an Event, so the Record is the Session's Event log. Nothing already written is rewritten. Any Instance loads a Session from its Facts, starting at its last Checkpoint. | the Session itself, snapshot | `record.Record`; a Store appends its `record.Entry` batches. |
| **Document** | The snapshot form of a Record: its Messages, Runs and latest Events as one JSON value, for export and tests. It is a copy that has no way to write, and not the form a Store keeps. | dump, export | `record.Document`, from `Record.Snapshot` and `Runner.Record`; `record.FromDocument` builds a Record back from it. |
| **Loop** | The cycle inside a Session that calls the model and runs the tools it asks for, until the Run ends. Also called the agentic loop. It is a concept, not a type. | | `executeRun` in `gotato.Session` |
| **Harness** | The industry's word for the code around a model: its loop, its tools and its context handling. In Gotato, the harness is a Session's Loop and Runtime. | framework | |
| **Runtime** | The part of a Session around its Loop: its Status, its queue, its state machine, its saving and its TTL. A Session is a Loop and a Runtime. | | In part: `gotato.Session` holds the Status, its state machine and the Steer and FollowUp queue. Saving is `store.Writer`, which the live Session writes every Step through (`gotato.Journal`). The warm copy and its TTL are the Runner's (`host.WarmPolicy`); the queues live only as long as the live Session, which is one Run. |
| **Transcript** | A Session's stored history: every committed Message, in order, and a declaration of what else it can do (its Capabilities). | history, log | `gotato.Transcript`, implemented by `record.Record` and `store.Writer` |
| **Capabilities** | What a Transcript declares it can do: its ID, its Journal, whether its Events are durable, whether a large Tool Result is spilled, an EventSource and the loaded Tools it restores. A Transcript that stores must declare every part a store needs, or `NewSession` refuses it. | optional interfaces, type assertions | `gotato.Capabilities`, from `Transcript.Capabilities()` |
| **Reserved key** | A Session metadata key that starts with `gotato.`. The Runner owns it: it names the Agent, keeps a TaskSpec's snapshot, a tool switch, the model last used and the cache key. A caller that sets one is refused. | setting, config key | `host.ReservedPrefix`, `host.ErrReservedKey` |
| **Context** | What the model sees on one Turn, built from the Transcript. | prompt, model view | `gotato.ModelContext`, built by a `ContextBuilder` |
| **Context builder** | The code that builds the Context from the Transcript on every Turn. The default shows the whole committed history, which keeps the request prefix identical from Turn to Turn so the provider's prompt cache hits. Extensions that transform or convert Messages run on its output. | prompt template, strategy | `gotato.ContextBuilder` and `gotato.ContextBuilderFunc`; `gotato.FullHistoryContext` is the default; `gotato.WithContextBuilder`, `profile.AgentProfile.ContextBuilder`. |
| **Context block** | One tagged piece of the system prompt, rendered as `<tag attr="value">text</tag>`; the tag marks a boundary or where the text came from. | prompt section | `gotato.ContextBlock`, in `ModelContext.System` |
| **Runner** | The part of a Go service that hosts Sessions: it starts them from AgentProfiles, routes messages to them, loads them from the Store and applies limits. | host, server | `host.Runner` |
| **Status** | The state a Session is in, such as idle, running or failed. The Session's state machine moves it. | state | `Session.Status` (created, idle, busy, closing, closed), and `gotato.RunResult.Status` for one Run: `completed`, `failed`, `canceled`, `deadline_exceeded` or `failed` (a Run whose reply or end could not be written is `failed` with `store_failure`). |

## Execution

| Term | Meaning | Not | In code today |
|---|---|---|---|
| **Run** | One request to a Session, from the input to the settled result. It may take many Turns. | job, task | `gotato.RunResult`, `host.RunRequest` and `host.RunResponse` |
| **Turn** | One model call plus the tool calls it asked for. | step, iteration | `turn_started`, `turn_ended` Events |
| **Round** | A user Message and every reply and Tool Result after it, up to the next user Message. A Steer starts a new Round; a Continue without a new prompt stays in its Round. A model whose Model facts set `RoundReasoning` is sent only the current Round's reasoning. | turn (a provider's word for it, and a Turn is something else) | no type; the model bridge (package `model`) finds it from the last user Message |
| **Step** | One thing a Run does that is written as it happens: the prompt, a model call starting, part of a streaming reply, a reply, Tools starting, a Tool Result, a continuation. A Turn has several. A crash loses at most the Step in flight. | | no type: the Events a Step stages are written together by `gotato.Journal.Write`, which `store.Writer` implements |
| **Message** | One entry in the Transcript: user input, an assistant reply, a tool result or a notice. It carries the Run that committed it, if any. | | `gotato.Message`, with `RunID` |
| **Notice** | A Message that tells the model a runtime fact the user did not say, from Gotato, the service or an extension: the last reply was cut at the output limit, the user has been away for three days and it is now this time, something happened outside the conversation. It waits in the same queue as a Steer, goes in right before the next model call, never starts a Round, and never starts or extends a Run. A compacted stretch of history is a Segment, not a notice. | system reminder, user message | `gotato.RoleNotice` and `Message.Notice`; `Session.Notice`, `Runner.Notice` (G-F29) |
| **Cut-off reply** | An assistant reply whose stream broke before the model finished. The Transcript keeps the text received so far as a log, and the reply is never sent to a model again. When the stream is sent again, the new reply is a reply of its own. | partial message | a `gotato.Message` with `StopReasonCutOff` |
| **Limits** | Settings that guard a real failure: the size of a message and of what a load reads, parallel tools, and the deadline of a model call and of a tool call. The core counts no Turns or tool calls, and a Run's own deadline is its `ctx`; a cap on Turns or calls is a team's `TurnStopper`. | quotas, caps on a Run | `gotato.CoreLimits`: message, transcript and queue sizes, `MaxParallelTools`, `ModelCallDeadline` and `ToolCallDeadline`. A cap on Turns or calls is a `TurnStopper` (`gotato/limits.go`). |
| **Continue** | Resume a Loop without new input. | | `Session.Continue` |
| **Steer** | Insert a Message into a running Loop, to change its course. | | `Session.Steer` |
| **Interrupt** | A Steer that does not wait for the Turn to end: it cuts the model call in flight short, keeps the text already sent as a Cut-off reply, and starts the next Turn of the same Run with its Message. A Tool in flight finishes first. It shares the Steer queue and its limit. | cancel, abort (an Abort stops the whole Run) | `Session.Interrupt`, `host.MessageKindInterrupt`; its Events carry the source `interrupt` (`gotato.MessageSourceInterrupt`). |
| **FollowUp** | Queue a Message that the Run picks up when it would otherwise settle, so the same Run goes on. | | `Session.FollowUp` |
| **Abort** | Stop a Run. The Run still settles with a result. | kill | `Session.Abort`, `Runner.AbortSession`; it is an `abort_requested` Event, and the Run's `run_ended` follows |

## Configuration

| Term | Meaning | Not | In code today |
|---|---|---|---|
| **Model** | The interface Gotato calls for a reply, as a stream of events. | LLM | `gotato.Model` |
| **Model config** | One model, described once: its name, its Model facts and its default Sampling. `Model.Config()` returns it, and a Model that states nothing returns the zero value. Gotato keeps no table of models. | model metadata, model profile, model table | `gotato.ModelConfig`, `Model.Config()` |
| **Model facts** | What a model is, as the team that runs it states it: its context window (a number of tokens, or `unknown` written out), how long its provider keeps the prompt cache, whether the provider takes back only the current Round's reasoning, and whether it checks a thinking block's prefix. Nothing overrides them and nothing is guessed from an address or a name. The runtime and the wire APIs read them. | capability, provider rule | `gotato.ModelFacts` (`Window`, `CacheRetention`, `RoundReasoning`, `ThinkingBinding`), `gotato.Window` |
| **Sampling** | A model's sampling and reasoning hints: temperature, output limit, reasoning effort and summary. The Model's defaults sit in its Model config, and an Agent's own (`profile.AgentProfile.Sampling`, or `WithSampling` on a Session), and a TaskSpec's after it, override them field by field. | model options | `gotato.Sampling`, `gotato.WithSampling`, `ModelRequest.Sampling` |
| **Provider** | A model service: an endpoint, a key, a Wire API and its models. In code it is values, not a type: a Wire API, a Connection and a Model config. | vendor, adapter | `model.New(wire, connection, config)` (see **Model bridge**) |
| **Model bridge** | The package that calls a model over HTTP: one `model.Client` joins a Wire API, a Connection, a Retry and a Classifier into a `gotato.Model`. Gotato provides and assumes no gateway; a team's own proxy is only an endpoint the Connection points at. | gateway, SDK | package `model`: `model.Client`, from `model.New` |
| **Wire API** | A request and response format that providers speak, such as OpenAI Chat Completions, OpenAI Responses or Anthropic Messages. Gotato ships each Wire API once, and any provider that speaks it works. A team that needs another writes one type that encodes a request and decodes its reply. | API format, protocol | `model.WireAPI`; `ChatCompletions`, `Responses`, `AnthropicMessages` |
| **Connection** | Where a model call is sent and as whom: the complete endpoint URL, a key, headers, a cache key header and an HTTP client. Authentication beyond a static key goes in the HTTP client's `RoundTripper`. | transport, credentials | `model.Connection`, `model.NewHTTPClient` |
| **Retry** | How often the model bridge sends a call again, and how long it waits, for a refused request or a cut stream. What is worth repeating is the Classifier's to say. | backoff policy | `model.Retry`, `model.DefaultRetry`, `model.WithRetry` |
| **Classifier** | The function that says what a failed model call means: the model bridge reads a Failure and gets a Verdict (retryable, overflow, the limit named). A team wraps the default to add its own wording. | error table | `model.Classifier`, `model.DefaultClassifier`, `model.WithClassifier`, `model.Failure`, `model.Verdict` |
| **Tool** | One capability a Session can call, with a name, a schema and an Effect. | function, action | `gotato.Tool` |
| **ToolSet** | A named group of Tools with a description and one source, such as an MCP server. It is a grouping, not the unit of loading: the model loads its Tools one by one. A team installs it active (always visible), listed in the catalog with all its tool names (the default), or folded. | toolkit | `gotato.ToolSet`, installed with `gotato.WithActiveToolSet`, `gotato.WithToolSet` and `gotato.WithFoldedToolSet`. |
| **Tool catalog** | What the model reads to find Tools it has not loaded: each ToolSet's description and, by its install mode, all its tool names or only a tool count. It is the description of `search_tools`, so it stays the same while Tools load. | tool list, registry | the description of `search_tools` (`gotato.SearchToolName`) |
| **Folded ToolSet** | A ToolSet whose catalog entry shows only its description and a count of its Tools. The model expands it with the `toolset` parameter of `search_tools`. | hidden ToolSet | `gotato.WithFoldedToolSet` |
| **Tool search** | The way the model loads Tools: `search_tools` loads Tools by name, runs a BM25 search that loads the top 3 and lists 5 more candidates, or expands a folded ToolSet. A loaded Tool stays until the next Compaction, which keeps the Tools called in the closed Segment or the kept tail. A team plugs in its own search with `ToolSearcher`. | discovery, retrieval | `search_tools` (`gotato.SearchToolName`), `gotato.ToolSearcher` and `gotato.WithToolSearcher`; the facts are `tool_loaded` and `tool_unloaded`. |
| **ToolSource** | Anything that supplies Tools at the start of each Turn. | | `gotato.ToolSource` |
| **Effect** | How much a Tool can change: read, write local, write external or destructive. | side effect, risk level | `gotato.ToolEffect` |
| **Effect cap** | The highest Effect an Agent's Tools may have. The model never sees a Tool above it, and the search never finds one. Only the Agent sets it, and there is none by default. | permission, policy, approval | `gotato.WithMaxEffect`, `profile.AgentProfile.MaxEffect` |
| **AgentProfile** | The Agent as a host registers it: a kind of Agent, like a process. It holds the name, instruction, model, Tools and ToolSets, Effect cap, Sampling, compaction parts, limits, a Run timeout and, optionally, the ReadBack that replaces the default. It holds Go values, so it is registered inline, or stored as a document that names a model and Tools of the Catalog. A Session looks its AgentProfile up by name each time it is built: a replaced profile reaches new and rebuilt Sessions and never a Run in flight. | agent spec, agent config | `profile.AgentProfile`; the ToolSet attachment is `profile.ToolSet{Set, Mode}`, with `profile.ToolSetListed`, `ToolSetFolded` and `ToolSetActive` |
| **TaskSpec** | A job that runs again, like a thread of an AgentProfile's process: a name, its AgentProfile, a Background and bounds that only narrow it (a subset of the Tools and ToolSets, an Effect cap no higher, a timeout no longer, an output limit no higher; its other Sampling fields may differ). A Run of a TaskSpec opens a new Session; the Background is added once, after the instruction, and the Record keeps the TaskSpec as it was, so every Instance builds the Session the same after the registered spec changes. Where its result goes, and when it runs, are the service's. | job, template, role | `profile.TaskSpec`, checked by `TaskSpec.Narrow` (`*profile.WidenError`, `*profile.UnknownNameError`) and applied by `TaskSpec.Apply`; `host.RunRequest.Task` and `RunRequest.TaskSpec`; the snapshot is the metadata key `gotato.task_spec` |
| **Catalog** | What a stored definition may name: the Models, Tools and ToolSets the service's code offers, each by name. A stored AgentProfile or TaskSpec selects from it and never adds to it, and a name it lacks is refused. | registry, plugin list | `profile.Catalog`, from `profile.NewCatalog(models, tools, toolSets)` |
| **Registry** | Where a host registers its AgentProfiles and TaskSpecs, and asks for them by name, one lookup for each. There are four registrations, each name once and a later one replacing it: inline as a value, or from a store by name, for each of the two kinds. A name that is not registered is not a definition, however many rows a store holds. | service locator | `profile.Registry`, from `profile.NewRegistry(catalog)`: `RegisterAgentProfileInline`, `RegisterTaskSpecInline`, `RegisterAgentProfileWithStore`, `RegisterTaskSpecWithStore`; `host.Config.Profiles`, `Config.DefaultAgent` |

## State and history

| Term | Meaning | Not | In code today |
|---|---|---|---|
| **Store** | Where Sessions are saved, as Records: memory, a file, or your own database. To save a Session is to write its Record to the Store. A Session built with `gotato.NewSession` alone keeps its Record in memory; a `host.Runner` over a Store saves it. The Store is the truth, and a Runner's memory is only a cache. | repository, persistence | `store.Store{Records, Liveness}`, two seams (`store.Records` for Records, `store.Liveness` for Instances' rows) and an optional `store.Lister`, with `store.MemoryStore` and `store.FileStore`, and the conformance suite `store/storetest` for your own |
| **Definitions** | An optional store of documents by kind and name, where a service keeps its AgentProfile and TaskSpec definitions. It saves and reads bytes and knows nothing of profiles. It is a contract of its own, not a part of the Store, and the service passes it to a registration. | profile table, config store | `store.Definitions` (`SaveDefinition`, `LoadDefinition`), `store.NewMemoryDefinitions`, `store.NewFileDefinitions`; the suite is `storetest.RunDefinitions` |
| **Entry** | One line of a Record, at a position no other Entry ever takes: a Fact or a Log entry. Every Entry is a stored Event, and its position is that Event's number. | row | `record.Entry`: its `Kind` is the Event's kind, and its `Seq` is the Event's number. |
| **Fact** | An Entry a rebuild reads: a Message, Tool calls that started, a metadata change, a Claim or a Checkpoint. The Context is built from the Facts on every Turn and is never stored. | | `record.LayerFact` |
| **Log entry** | An Entry that records what happened, for people and telemetry: a Run's start and end, usage, a model call, a retry, a release, part of a streaming reply. A rebuild does not read it, except the reply parts of a Run that never ended. | | `record.LayerLog` |
| **Compaction** | Closing what came since the last Checkpoint into a Segment, and appending a Checkpoint that lists the Segments it uses and holds the kept tail. The Messages it covers stay in the Record but are no longer loaded. | summarization, pruning | `record.Compact(ctx, store, compactor, cfg)`, `record.AutoCompact(store, compactor)`, through `Record.CloseSegment` (which lists the Segments itself and sets the loaded Tools). The frame is a `record.Compactor`; it closes a Segment built by code, with a Recap from `ModelRecap` when a team turns it on, and merges the oldest Segments when they pass their budget (`Record.MergeSegments`, G-F06). |
| **Checkpoint** | A Fact that holds the whole state of a Session's Facts at one point, so it stands in for everything before it. Every Record starts with one, and Compaction appends one with every Segment, the kept tail and the loaded Tools. A load starts at the last one. A compaction writes the Segment first and its Checkpoint after, in one batch; a Fork writes `session_created`, which is its Checkpoint, first, and then the inherited `segment_closed` Entries, in the same batch ([specs/record.md](specs/record.md)). | snapshot | the `session_created` and `compaction_ended` Entries (`Entry.IsCheckpoint`), and `Record.Checkpoint`. It keeps the Tools the model had loaded (`Tools`) and lists Segments by number; a compaction writes one with every Segment it closes (G-F06). |
| **Segment** | One stretch of a Session's history that a Compaction closed: the user's messages and each Run's final reply word for word, one line for each tool call inside its Run, and a Recap at its end. It has a number and is never rewritten, except that the oldest are merged at last, into the one **merged Segment** that opens the Context: a Segment that holds one Recap for the Segments it stands for, and is named by their range, `<segment n="1-3">`. The model can read any Segment back in full with `read_segment`, a merged one's originals by their own numbers. A Segment is written once, as its own Entry, and a Checkpoint lists the Segments it uses by number. | epoch (the Record epoch and a Claim's Epoch are other things), summary | `gotato.Segment`, stored as a `segment_closed` Entry and closed by `record.Compact`; a merged Segment is a `gotato.Segment` with `Merged` set, closed by `Record.MergeSegments` (G-F06) |
| **Recap** | The end of a Segment, which the Agent's own model writes on the cached prefix: what happened, the key facts the tools returned, the decisions, what is still open, and, for a Run compacted mid-Run, where it stands. A Recap fails when the reply calls a tool, is cut off at the output limit, does not start with one of the five `## ` headings, uses any other `## ` heading, or has no `## What happened`; a heading with nothing under it may be left out. A Segment whose Recap failed is kept without one, and its compaction says why (`recap_error`). What writes it is a `record.RecapWriter`, which is `ModelRecap` for the Agent's model and `TruncateRecap` for tests; with no writer set, a Segment has no Recap. A merged Segment's Recap is written from the Recaps of the Segments it merges, and by code, as a digest, when no model writes it. | summary | `gotato.Segment.Recap` holds the text; `record.RecapWriter`, `RecapRequest`, `ModelRecap` and `TruncateRecap` write it, and a Segment has one only from a writer that is set (G-F06) |
| **Compactor** | The frame of a compaction: it runs the parts in order and alone writes and holds the guarantees (one batch, no Segment dropped or moved, a Segment written once, readable refs, once per Turn). A part returns a value; a part that fails, panics or breaks a rule drops that compaction and never the Run. A nil part is its default. | pipeline, strategy | `record.Compactor{CompactPolicy, Trigger, Cut, Builder, Recap, Merge}`; `profile.AgentProfile.Compact` (G-F06) |
| **Trigger** | The part that says when a compaction is due, and why. | scheduler | `record.Trigger` (`Due(ctx, TurnState) (CompactionWhy, bool)`); the default is `CeilingTrigger` |
| **Cutter** | The part that says where the kept tail starts in the Messages since the last Checkpoint. The frame moves the cut to a Turn boundary. | | `record.Cutter` (`Cut(stretch, CutInfo) int`); the default is `TailBudget{KeepMessages, TailTokens}` |
| **Builder** | The part that renders the closed Messages as a Segment. The frame stamps its numbers and refuses a Segment that breaks a rule. | | `record.Builder` (`Build(closed, SegmentInfo) (Segment, error)`); the default is `CodeSegments{SegmentSettings}` |
| **Picker** | The part that says how many of the oldest Segments a merge replaces: two or more. | | `record.Picker` (`Pick(segments, budgetTokens) int`); the default is `OldestToHalf` |
| **SegmentStore** | What a compaction reads and writes: the Context's Segments, tail and loaded Tools, and two batches, one that closes a Segment and one that merges. A `*record.Record` is one, and so can any Transcript. | | `record.SegmentStore`; `Record.CloseSegment`, `Record.MergeSegments` |
| **Spilled result** | A Tool Result over one page (about 8K tokens), stored in full in the Record as an Entry of its own. The Message in the Transcript holds a preview and a ref, `result:<call_id>`, and the model reads the rest page by page with `read_result`. A load does not read the body until it is asked for. A Session spills only with a **ReadBack** installed. | truncated result, attachment | `ToolResult.Spilled`, the `tool_result_spilled` Entry, `read_result`; `CoreLimits.SpillPreviewBytes` sets the preview |
| **ReadBack** | What makes the originals Gotato moved out of the Context readable again: a ToolSource that offers `read_result` and `read_segment`, and the one owner of the page size. | | `gotato.ReadBack` (a `ToolSource` and `PageBytes() int`), `gotato.WithReadBack`; the default is `record.ReadBack{Originals, PageSize, Location}`, which a service installs over its store; an AgentProfile may replace it with `profile.AgentProfile.ReadBack` |
| **Page size** | The most one page of a read holds, in bytes: 32 KiB, about 8K tokens, by default. The spill threshold, the pages a preview counts and the pages of both read tools all use this one number. | page limit | `gotato.ReadBack.PageBytes`, `record.ReadBack.PageSize`, `record.DefaultPageBytes` |
| **Originals** | Where a ReadBack reads the originals from: a Message by its ref, and the Messages a Segment closed. | | `record.Originals` (`Ref`, `Segment`), `record.OriginalsOf(rec, log)`; `ErrNoOriginal`, `ErrRemoved` |
| **Ref** | The name of one original a Segment or a spilled result points to: `result:<call_id>` for a Tool Result, `msg:<message_id>` for a user or assistant Message. The form is a contract, since a Segment carries it forever. | id, link | the public package `ref`: `ref.Result`, `ref.Message`, `ref.Parse`, `ref.Safe`, `ref.ReadResult`, `ref.ReadSegment` |
| **Fork** | Starting a new Session from another Session's Record, as a branch at one point of its log. It writes the Store and activates nothing. | clone | `record.Fork`, `Runner.Fork`: the new Record starts with a Checkpoint of its parent, and names the position it branches at. |

## Watching and extending

| Term | Meaning | Not | In code today |
|---|---|---|---|
| **Event** | Something that happened to a Session or an Instance, as a value of its own type, named for what happened, such as `run_started`. A stored Event is an Entry, numbered by its position in the Record. A delta, such as `text_delta`, is only sent. An Instance Event happens where no Claim is held, and goes only to that Instance's Subscriptions. | log line | `gotato.Event`, a sealed interface with one Go type for each kind, such as `gotato.RunStarted`, each with a `gotato.Header` and its own `Kind()` and `Class()`; embedding the Header and stating the two is what makes a type an Event, a host's own included. The Instance Events of a Runner are types of `host`, such as `host.RunRejected`. |
| **Subscription** | A queue of Events, in order: a Run's, a Session's from any number, or an Instance's. A Session never waits for one; a subscriber that falls behind catches up from the Record. | observer, listener | `gotato.Subscription`, from `Session.Subscribe` and `SubscribeRun`, and from `Runner.StreamRun`, `StreamSession` (a Session's stream for a client that reconnects, with the Record's epoch) and `SubscribeInstance`. A `gotato.Feed` fills them. |
| **Feed** | What fans a stream of Events out to Subscriptions. A Session has one, and an Instance has one that mixes every Session's Events. Publishing never blocks: a Session does not wait for a slow subscriber. | broker, bus | `gotato.Feed`, with `Subscribe` and `Close`; the calls that make one, publish to one and hand one to a Session belong to the host and are in `internal/hostlink`, not in the API. |
| **Event source** | Where a Subscription that fell behind reads stored Events again, by number. The Record is one. | | `gotato.EventSource`, implemented by `store.Writer` |
| **Journal** | What a Transcript declares in its Capabilities when it keeps the Session's stored Events: the Session hands it the Events of each Step to write, in order, and it returns them numbered. Without one, the Session numbers its Events in memory and stores none. | event writer | `gotato.Journal`, implemented by `record.Record` and `store.Writer` |
| **Extension** | Code that wraps the Loop at a defined point, such as before a Tool runs or at the end of a Turn. One value may take part in several stages. There are six stages: `TurnPreparer` (before a model call; the one safe point to rewrite the Transcript), `ContextTransformer`, `MessageConverter`, `PreToolUse`, `PostToolUse` and `TurnStopper`. | hook, middleware, plugin | `gotato.WithExtension` and the stage interfaces named here |

## Cluster and positioning

| Term | Meaning | Not | In code today |
|---|---|---|---|
| **Instance** | One running copy of your service. On Kubernetes it is a pod, and the README and the proposal say "pod" for that reason; the glossary and the code say Instance. A pod and an Instance are the same thing. | replica, node | `host.Config.Instance` names it |
| **Not writer** | What an error says when a message reaches an Instance that is not the Writer of the Session's Run going on: the code `not_writer`, which is also Not run and Retryable. It carries the Writer's advertised address, so the caller, or the HTTP endpoints when a team opts in, sends the message there. | redirect, forward | `host.CodeNotWriter`, `host.WriterOf` |
| **Not run** | What an error says when nothing with side effects happened, so the same request can go to another Instance without running twice. A refusal before a Run starts is not run; a store failure may have run, and is not marked. | | `gotato.NotRun(err)`, `RuntimeError.NotRun`, HTTP `Gotato-Not-Run` |
| **Retryable** | What an error says when the same request, sent again later, may succeed. | | `gotato.Retryable(err)`, `RuntimeError.Retryable` |
| **Admission** | The decision whether a Run may start on an Instance. In order: a draining Instance refuses, the memory bound refuses (Activation limit), and then the service's own Admitter decides. The Run it is asked about is an `Admission` (the Session, the Agent and, for a TaskSpec's Run, the TaskSpec's name), and the Instance's counts are its `Load`. | rate limit, quota | `host.Admission` and `host.Load`, decided by a `host.Admitter`; `host.Bounds` holds the memory bound and the `host.QueuePolicy` for a busy Session |
| **Admitter** | The policy of a service for whether a Run may start: it is given the Run, the Instance's `Load` and the caller's `ctx`, which carries who asks, and returns a `release` the Runner calls once when the Run ends, or a refusal that is not run. One tenant gets ten Runs, another fifty. The default is `Limits{MaxActiveRuns}`. | quota, rate limiter | `host.Admitter`, `host.Limits`, `host.Config.Admitter` |
| **Drain** | Finishing work before an Instance shuts down: it takes no new Sessions, lets every Run finish, saves, releases its Claims, and only then disconnects. | | `Runner.Drain`: it marks the Liveness row draining, admits no new Run and takes no Session over, waits for the Runs in flight, and at its deadline stops, saves and releases the rest; `Runner.Close` then removes the Liveness row. |
| **Writer** | The one Instance allowed to append to a Session's Record at a time. It holds the Claim while a Run goes, not while a warm Session idles, and it is wherever the Load balancer sends the Session's requests. | owner, leader, master | `host.Runner` as its Instance, writing through a `store.Writer` |
| **Claim** | A Writer's hold on a Record: a Fact naming the Instance and an Epoch, written at the position after the head that Instance read. While the Record is busy, it is valid as long as that Instance's Liveness row is alive; a Record that is not busy is claimable at once, whoever claimed it last ([specs/multi-instance.md](specs/multi-instance.md)). | lease, lock | `record.Claim` |
| **Epoch** | A number in a Claim. It grows when a different Instance claims the Record, and on the first Claim; the same Instance claiming again keeps it. A Claim takes a position in the Record, so an Instance that lost its Claim always writes to a taken position, and the Store refuses it. | version, generation | `record.Claim.Epoch` |
| **Record epoch** | An identity a Record gets when it is created. It changes only if the Record is deleted and created again under the same ID, so a number a client holds means the same Event only within one epoch. A stream that resumes is refused when the client's epoch is not the Record's, and an open stream follows one epoch and ends when its Record is deleted or created again. It is not the Epoch of a Claim. | version, generation | `record.Record.RecordEpoch`, `record.Header.Epoch`; `record_epoch` in `session_created`, in the summary a create or fork answers and in a Run's result. |
| **Activation limit** | The hard limit on the Sessions an Instance has active; with the warm Session, the Sessions it holds in memory, idle ones included. At the limit, the Instance first evicts the longest-idle warm Session. Only when every live Session is running a Run does it refuse a Run that would activate another, as not run, so the Load balancer sends it to another Instance. | quota, rate limit | `host.Bounds.MaxActiveSessions`, `host.ErrOverloaded`, `host.CodeOverloaded` |
| **Liveness row** | One row per running Instance in the Store, renewed on a heartbeat and timed by the Store's clock. While a Record is busy, its Claim is valid as long as the holder's row is alive: when the row expires, every busy Claim of that Instance ends at once, and an Instance that stops removes the row, with the same effect. A Record that is not busy is claimable at once, so its holder's row does not matter. It can also carry the Instance's advertised address. | heartbeat (the act of renewing it) | `store.Liveness` (`Beat`, `Instance`); `host.Runner` renews its row and removes it with `Runner.Close`. |
| **Advertised address** | An address an Instance puts in its Liveness row, an optional setting: where a caller can reach that Instance's own endpoint. It is what Not writer names. Gotato reads it and never connects to it. | service discovery, membership | `host.Config.Address`, `store.InstanceRow.Address` |
| **Load balancer** | The router in front of your Instances. It sends every request for one Session to one Instance by hashing its `session-id`. It belongs to your infrastructure, not to Gotato. | gateway (Gotato provides and assumes none; its `model` package talks to model providers) | |
| **Cloud agent** | An Agent whose Sessions live in your own cluster and are called like any other service. | | |
| **Agent-as-a-Service** | Gotato's mission: any service can easily become an agent, and the agent becomes the cloud service itself. Callers start and talk to Sessions like any other API, inside your own infrastructure. | | |
